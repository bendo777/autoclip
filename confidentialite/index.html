Politique de confidentialité

AutoClip – dernière mise à jour : 24 novembre 2026

AutoClip fonctionne sur l'ordinateur de son propriétaire. Il n'a ni serveur en ligne ni base de données partagée.

Données utilisées

  • TikTok : identifiant du compte (open_id), nom affiché, et les jetons d'accès nécessaires pour publier des vidéos sur ce compte.
  • Google / YouTube : identifiant et nom de la chaîne, et les jetons d'accès nécessaires pour envoyer des vidéos sur cette chaîne.

Utilisation

Ces données servent uniquement à publier les vidéos produites par AutoClip sur les comptes connectés. Elles sont enregistrées localement sur l'ordinateur du propriétaire, ne sont ni vendues, ni partagées, ni utilisées à des fins publicitaires.

Conservation et suppression

Les jetons restent enregistrés tant que le compte est connecté. Déconnecter le compte dans AutoClip les supprime ; l'autorisation peut aussi être retirée depuis les paramètres du compte TikTok ou Google.

Services tiers

Les vidéos sont envoyées via les API officielles de TikTok (Content Posting API) et de YouTube (YouTube Data API). Les données traitées par ces plateformes relèvent de leurs propres politiques de confidentialité.
